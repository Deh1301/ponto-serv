# 🏪 Ponto Serv — Landing Page

Landing page desenvolvida para uma loja de eletrodomésticos, com o objetivo de criar uma presença digital para o estabelecimento e facilitar o acesso de clientes às informações da loja.

O projeto foi desenvolvido a partir de uma necessidade real de um estabelecimento comercial, proporcionando experiência prática desde o desenvolvimento da interface até a publicação do site.

## 🌐 Demonstração

🔗 **Acessar o site:**
https://deh1301.github.io/ponto-serv/

## 📋 Sobre o projeto

O **Ponto Serv** é uma landing page desenvolvida para apresentar uma loja de eletrodomésticos na internet.

A aplicação foi estruturada com foco em uma navegação simples e objetiva, permitindo que os visitantes encontrem as principais informações do estabelecimento de maneira rápida.

Este projeto também faz parte do meu portfólio e representa uma experiência prática de desenvolvimento de uma solução para uma necessidade real.

## 🚀 Tecnologias utilizadas

* **HTML5** — estruturação da página
* **CSS3** — estilização e layout
* **JavaScript** — funcionalidades e interações
* **Node.js** — ambiente utilizado durante o desenvolvimento
* **Git** — controle de versão
* **GitHub** — gerenciamento e hospedagem do código
* **GitHub Pages** — publicação da landing page

## 💡 Principais objetivos

* Criar uma presença digital para o estabelecimento.
* Desenvolver uma interface simples e intuitiva.
* Disponibilizar as informações da loja de forma acessível.
* Criar uma página adequada para acesso em diferentes dispositivos.
* Aplicar conhecimentos de desenvolvimento web em um projeto real.

O projeto foi desenvolvido considerando diferentes tamanhos de tela, buscando proporcionar uma experiência adequada tanto em computadores quanto em dispositivos móveis.
